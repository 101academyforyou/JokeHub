# JokeHub 😄

一個 Chrome / Edge 瀏覽器插件：點擊工具列上的 JokeHub 圖示，就會跳出小視窗顯示笑話。

## 特色

- 點擊圖示即開啟小視窗，先看題目，按「看答案」揭曉笑點，按「下一則」換一則。
- 笑話以洗牌方式播放，一輪看完前不會重複。
- **不含說謊內容**：所有笑話都經過 `jokes.js` 中的 `isHonestJoke()` 過濾，
  只要含有「說謊、騙、吹牛、假裝、lie、fake……」等關鍵字就不會顯示；
  測試也會檢查笑話庫裡的每一則笑話都通過這項規則。
- 完全離線，不需要任何權限，也不會收集資料。
- 支援淺色 / 深色模式。

## 安裝方式（開發者模式）

1. 下載或 clone 這個專案。
2. 打開 Chrome，網址列輸入 `chrome://extensions`（Edge 為 `edge://extensions`）。
3. 開啟右上角的「開發人員模式」。
4. 點「載入未封裝項目」，選擇本專案資料夾。
5. 工具列出現 JokeHub 圖示後（可點拼圖圖示把它釘選），點一下即可看笑話。

## 新增笑話

在 `jokes.js` 的 `JOKES` 陣列中加入 `{ q: "題目", a: "答案" }`，然後執行：

```bash
npm test
```

測試會確認新笑話不含說謊相關內容，且沒有重複。

## 檔案結構

```
manifest.json   插件設定（Manifest V3）
popup.html/css  小視窗畫面
popup.js        顯示笑話的邏輯
jokes.js        笑話庫與「不說謊」過濾規則
icons/          插件圖示
tests/          自動測試
```
