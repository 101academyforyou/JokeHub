# JokeHub 😄

一個 Chrome / Edge 瀏覽器插件：點擊工具列上的 JokeHub 圖示，就會跳出小視窗顯示笑話。

## 特色

- 點擊圖示即開啟小視窗，先看題目，按「看答案」揭曉笑點，按「下一則」換一則。
- 55 則繁體中文、全年齡笑話；可選「全部／腦筋急轉彎／雙關語／冷笑話」。
- 所選分類以洗牌方式播放，一輪看完前不會重複；切換分類會重新洗牌並收起答案。
- 按「複製笑話」即可複製完整題目與答案（即使尚未揭曉），使用 `navigator.clipboard`，不新增權限。複製失敗會顯示提示，可再按一次重試。
- **不含說謊內容**：所有笑話都經過 `jokes.js` 中的 `isHonestJoke()` 過濾，
  只要含有「說謊、騙、吹牛、假裝、lie、fake……」等關鍵字就不會顯示；
  測試也會檢查笑話庫裡的每一則笑話都通過這項規則。
- 完全離線，不需要任何權限，也不會收集資料。
- 支援淺色 / 深色模式。
- 待辦清單：新增、勾選／取消完成、刪除及未完成數量；輸入限 1～200 字。使用 `localStorage` 儲存在此瀏覽器的擴充功能本機空間，不會上傳或跨裝置同步，不新增權限；移除擴充功能或清除其資料會清除清單。儲存失敗時保留原清單與輸入並顯示提示。

## 安裝方式（開發者模式）

1. 下載或 clone 這個專案。
2. 打開 Chrome，網址列輸入 `chrome://extensions`（Edge 為 `edge://extensions`）。
3. 開啟右上角的「開發人員模式」。
4. 點「載入未封裝項目」，選擇本專案資料夾。
5. 工具列出現 JokeHub 圖示後（可點拼圖圖示把它釘選），點一下即可看笑話。

## 新增笑話

在 `jokes.js` 的 `JOKES` 陣列中加入 `{ q: "題目", a: "答案", category: "腦筋急轉彎" }`，然後執行：

```bash
npm test
```

分類必須是「腦筋急轉彎」、「雙關語」或「冷笑話」。新增前須人工審閱：全年齡、繁體中文、笑點不涉及任何欺瞞；關鍵字過濾無法取代內容審閱。所有畫面資料必須透過 `getHonestJokes(category)` 取得，該函式會先執行 `isHonestJoke()` 再依分類篩選。

需要 Node.js 18 以上，不需要 `npm install`。目前 15 項測試涵蓋原有過濾與去重、笑話數量與分類、分類切換與洗牌、複製成功／失敗／非同步切換，以及 Manifest V3 限制；另涵蓋待辦新增／完成／刪除、重新開啟保留、輸入驗證與讀寫失敗。
